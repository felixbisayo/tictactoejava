
 # Tic-Tac-Toe Game (Java Swing)

A two-player Tic-Tac-Toe desktop application developed using Java Swing. The game provides a graphical interface where two players take turns placing X and O on a 3 × 3 grid.

## Features

- Graphical user interface built with Java Swing.
- Two-player turn-based gameplay.
- Automatic winner detection.
- Draw detection when all cells are occupied without a winner.
- Automatic game restart after a completed round.
- Interactive buttons for selecting grid positions.

## Technologies Used

- Java
- Java Swing
- AWT (Abstract Window Toolkit)
- Object-Oriented Programming
- Event Handling (`ActionListener`)

## How to Run

### Prerequisites

- Java Development Kit (JDK) installed.
- An IDE such as IntelliJ IDEA, Eclipse, or VS Code, or the Java command-line tools.

### Running the Application

1. Clone this repository:

   ```bash
   git clone https://github.com/felixbisayo/tictactoejava.git
   ```

2. Open the project in your preferred Java IDE.

3. Ensure the source file is located in the `mainstuf` package.

4. Run the `main` method in `xando.java`.

## How to Play

1. Launch the application.
2. Two players share the same computer.
3. Players take turns selecting an empty cell.
4. The first player to align three matching symbols horizontally, vertically, or diagonally wins.
5. If all nine cells are occupied without a winner, the game ends in a draw.
6. A new game starts after the round ends.

## Project Purpose

This project was developed to practise Java programming, graphical user interface development, event handling, and conditional logic.

It provided practical experience in building an interactive desktop application using Java Swing.
